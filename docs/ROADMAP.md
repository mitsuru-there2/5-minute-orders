# ロードマップ

1. **M0 開発基盤（今回）**: 原案保存、Godot起動、レイヤー分離、SPEC、固定版セットアップ、テスト、CI。
2. **M1 ルール検証**: マップ・国家・指揮官・命令モデル、衝突・勝利条件を決定。決定的な同時解決と観測情報生成をテストする。
3. **M2 プレイ可能版**: マップ、指揮官カード、命令確認、戦記ログ、観測情報のみを使うAI。ローカルDBの方式を選定し保存・再開を実装。外部サーバーなしで2国家の1試合が完了する。
4. **M3 スマホ検証**: 日本語フォント、セーフエリア、タップ領域、通信を無効にした状態でのローカルDB保存・復帰、実機で入力時間と読み合いを評価する。
5. **M4 拡張判断**: 面白さの評価を受けて国家差、指揮官能力・加入を設計。将来のオンラインマルチプレイに向けて費用・運用・権威サーバーの構成を判断する。

## 保留事項

- ローカルDB製品とGodot連携方式（保存機能の実装前にモバイル対応を検証して選定）。

- アプリ識別子、Apple Team ID、ストアアカウント、配布用署名。
- 初回実機検証で優先するOS・対象端末と最低対応OS。
- 勝利条件、1試合のターン数、戦闘と退却、経済・補給の粒度。
- 外部公開ライセンス、ゲーム素材の権利表記。

次の開発はM1から始める。保留のゲームルールをSPECで具体化してからコードを追加する。
