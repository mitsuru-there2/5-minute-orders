# SPEC 007: 兵種・徴兵・守備隊

作成日: 2026-09-11 / 状態: **指揮官不在地での直接徴兵は採用済み・兵種等は提案・未実装**。
関連: [指揮官](004-commanders.md) / [経済](005-territory-development.md) /
[指導者](006-factions-leaders.md) / [脱落処理](003-release-map-factions.md)

## 1. 検討範囲

ユーザーは指揮官が徴兵するユニットの種類・購入方法と、指揮官不在の領土に守備兵を置くかを検討したい。
追加回答により、指揮官がいなくても各自領で直接守備兵を徴兵できる方針を採用。
兵種・編成上限・費用・処理時点等は本書の提案であり、まだ確定していない。
資金で兵を整えること、中立軍から加入するのは指揮官だけ、海軍なしという既存要件を維持する。
SPEC 002の「兵種なし」、SPEC 004の単一兵力を回復する補充案との比較・改訂候補とする。
人気・科学力の補正対象はまだ未決定で、本書から軍事補正を自動採用しない。

## 2. 初回の3兵種案

| 兵種 | 役割と能力の方向 | 制約 | 仮の価格比 |
| --- | --- | --- | --- |
| 歩兵 | 安価な主力。防衛命令で守備に適する | 攻撃時の専門能力は持たない | 2 |
| 弓兵 | 同じ軍団に歩兵がいると、攻撃時に支援効果を得る | 単独編成では支援効果なし | 3 |
| 騎兵 | 平地への攻撃で突撃効果を得る | 森・山への攻撃では突撃なし | 4 |

価格比は調整用で、実際の資金額や戦闘倍率ではない。弓兵・騎兵を歩兵の完全上位にしない。
弓兵は同じ戦闘内の支援であり、別マスへの遠隔射撃命令・射程管理は設けない案。
騎兵でも通常移動は上下左右1マス。指揮官の強行軍能力や渡河特性とは分ける。
突撃と渡河攻撃の併用、弓兵支援の対象・重複上限、歩兵の防衛効果は戦闘式と合わせて確定する。
攻城兵・船・派閥専用兵は初回案に含めない。全派閥が同じ3兵種を開始時から買える案。
研究による兵種解禁は追加しない。指揮官の型で兵種を購入不可にすることもしない。

## 3. 軍団の編成案

指揮官1人につき軍団1つ、最大3部隊を候補とする。1部隊は複数の兵士をまとめた購入単位。
歩兵2＋弓兵1、歩兵1＋騎兵2など混成・同種の重複を許す。
部隊ごとに別の移動先や命令を与えず、軍団全体で1命令。兵種の選択は主に徴兵時に行う。
3枠という数値、部隊内の兵力・損耗の粒度は未採用。
既存の現在兵力／上限兵力は各部隊の兵力と軍団合計へ整理する必要があり、
戦闘の損害を部隊へどう割り振るかを決めるまで実装契約にしない。

## 4. 購入・補充案

指揮官の既存「補充」を「徴兵・補充」という1命令へまとめる。
自領の現在地に留まり、国家共有の資金で兵種と購入数を指定する。
新しい部隊の追加と既存部隊の欠員補充を同じ画面で扱い、1命令あたりの総募集量に共通上限を置く。
その上限・欠員補充の単価は未決定。無制限の一括購入や無料での兵種変更は認めない案。
首都以外の自領でも募集可能とし、兵舎・地形別購入制限・遠隔への即時配送は設けない案。
兵力0の加入指揮官も自領で募集可能。加入地点から自領へ戻る規則はSPEC 004で別途決める。

- 開始時の資金から他の命令と合わせて費用を予約する。同ターンの徴税収入は使えない。
- 解決中に戦闘へ参加、退却、所在領土を喪失、指揮官を喪失、または国家が脱落した場合は募集不成立。
- 成立した新兵はターン末に加わり、翌ターンから戦う。同ターンの襲撃を購入予定兵で防がない。
- 募集が不成立なら予約を解除し、徴兵費を消費しない案。他の費用の返還規則をこれで確定しない。
- 終局時に次ターンの兵は作らない。敵の秘密命令で受付結果を変えない。
- 風原連邦の行軍補給は既存部隊の欠員補充のみを対象とする案。移動中の新部隊追加・守備隊設置は不可。

徴兵UIは兵種別の数量と合計金額・残り枠・成立時点を示す。
部隊のHP回復と新部隊購入で同じ兵を二重計上しない契約を戦闘・補充の数値確定時に作る。
維持費や自動補充は本案に加えないが、軍団・守備隊の上限と徴兵の行動費用で蓄積を制限する。

## 5. 指揮官不在の守備隊案

配置済みの守備隊が指揮官なしでその領土を守る方式を推奨する。
指揮官不在でも毎ターン命令を入力する軍団とはせず、移動・攻撃・開発・偵察・自動補充はしない。

- 各自領の領土画面から守備隊を直接徴兵する（指揮官不在でも可能という方針は採用済み）。
  兵種は歩兵だけ、1領土最大1部隊を候補とする。
- 領土ごとの徴兵予約として扱い、指揮官・指導者の命令枠を使わない案。
  1領土1ターン1予約、国家全体の資金から軍団の徴兵と合わせて費用を予約する。
  複数領土で同時に購入可能とし、一覧で数量・合計額・取消を扱えるようにする。
- 守備隊は土地に残り、指揮官の出発後も自動防衛する。指揮官の5人／6人枠は消費しない。
- 守備隊の欠員補充も領土画面から有料で行う案。占領直後に無償で守備兵は生まれない。
- 開始時点で自領の土地だけ予約可能。同ターンに占領予定の土地には予約できない。
- 募集はターン末に成立し、その土地で戦闘が起きた場合、領有を失った場合、国家脱落・終局時は不成立。
  予約を解除し、新兵が同ターンの戦闘に参加したり、奪われた土地へ出現したりしない案。
- 指揮官の存在や行動はこの募集の成立条件にしない。指揮官の開発と同時指定も可能な案。
- 首都には開始時から歩兵守備隊1部隊を置く案。初期指揮官の軍団とは別の兵として状態に記録する。
- 守備隊は地形・領土開発の防衛補正を受ける。歩兵の防衛効果も使う案だが、守備隊専用の追加倍率は付けない。
- 味方軍団が同じ場所で戦うときは同じ戦闘に参加する。軍団と守備隊の損害配分は要定義。
- 守備隊は退却せず、敗北時に除去する案。勝利時の損害は残る。
- 国家脱落では守備隊も軍として除去する。敵国の守備隊を占領で継承しない。

初回は軍団と守備隊の相互移管を設けない案。配置・回収による無償回復や兵の複製を避ける。
指揮官を解雇しても軍団の兵を守備隊へ自動移管しない。解雇の軍団処理は引き続きSPEC 004で確定する。
守備隊は小規模な侵入を防ぐ役割とし、主力軍を止めるには指揮官による防衛も必要な強さを目指す。
8×8の全領土へ配置する作業が定石にならず、首都・要衝に絞る価値を費用・強さ・試合長で検証する。

## 6. 情報と検証項目

自国は編成・欠員・守備隊を正確に観測する。敵の兵種を通常観測でどこまで見せるかは未決定。
精察で詳細編成を見せる候補とし、深緑盟約の兵数隠蔽から枠数経由で正確な戦力が漏れないよう統合する。
AIにも許されたObservationだけを渡し、戦闘ログからの公開範囲も共通化する。

実装前に決める事項:

1. 3兵種・混成最大3部隊を採るか。兵力の粒度、攻撃・防御・支援・突撃と損害配分を確定する。
2. 購入額・募集量上限・欠員補充価格・兵種変更と部隊解散の可否を確定する。
3. 守備隊の直接徴兵は採用済み。命令枠・初期守備隊・上限・募集条件・敗北時処理を確定する。
4. 人気・科学力の採用補正との重複、通常観測・精察・隠蔽との優先順位を定める。

必要な検証:

- 同じ状態・命令・seed・ルール版から同じ損耗と編成になる。
- 合計支出・軍団枠・守備隊上限・募集量の超過を確定前に拒否する。
- 戦闘中の募集兵を戦力に加えず、不成立の予約を正しく解除する。
- 指揮官不在でも守備隊は戦い、不在地での直接募集・補充でも国家資金と領土上限を守る。
- 移動・解雇・占領で兵が複製されず、国家脱落で全守備隊が消える。
- 全歩兵・混成・全騎兵や、守備隊だけを増やす戦略を比較し、単一編成の常時最適を避ける。
- 最大人数時も軍団単位の命令が維持され、部隊単位の毎ターン操作が増えない。

文書のみ。兵種・徴兵・守備隊の実装やバランス検証は行っていない。
