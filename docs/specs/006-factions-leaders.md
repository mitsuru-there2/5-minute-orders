# SPEC 006: 4派閥と首都の指導者

作成日: 2026-09-10 / 状態: **首都固定・指導者別枠・人気と科学力の導入は採用済み、数値等は提案、未実装**。
関連: [基本仕様](003-release-map-factions.md) / [指揮官](004-commanders.md) /
[開発・経済](005-territory-development.md)

最新の解決順: [SPEC 009](009-turn-timing.md)の「Tの作業・徴兵完了→T+1開始時の戦闘」を採用。
本書の旧「戦闘後に開発・休養・指導者行動」「戦闘で作業取消」は同SPECに置き換える。
ターン境界の細部はSPEC 009で確認中。

## 1. 採用された要件

- 各国家に指導者を置き、指導者が毎ターン実行するアクションを設ける。
- 首都は試合中に変更できず、指導者は首都から移動できない。
- 首都が陥落した国家は脱落する。残存1国が勝利し、全国家同時脱落は引き分けという既存要件を維持する。
- 指揮官の在籍上限は通常5人、4派閥のうち1派閥のみ6人。
  指導者は指揮官の在籍上限とは別枠（ユーザー承認済み）。
  開始時は指導者1人＋指揮官1人、最大は指導者1人＋指揮官5人（特定派閥6人）。

追加承認（2026-09-10）:
- 4派閥の組織・隠蔽・行軍補給・渡河という方向を了承。名称・具体的な適用条件は引き続き調整する。
- 指導者に人気を持たせ、人気の高さによる補正を設ける。徴税で下がり、人気向上アクションで上がる。
- 研究で科学力が上がり、その高さによる補正を設ける。
- 指導者のアクションに徴税・研究・人気向上を含める。
- 選択回答4A: 徴税・研究・人気向上から毎ターン1命令。首都開発は指揮官が担当する。
- 選択回答5C: 科学力は資材生産と軍の攻撃・防御の両方へ補正。数値・適用式は未確定。
- 59A・60B・61A: 人気の対象は通常の資金収入のみ。科学Lv0〜3、1Lvごとに資材+20%・攻撃防御+10%。
  研究1回で1点、累計2／5／9点でLv1／2／3。Lvごとの補正は加算し、反復乗算しない。

「Faction」は文化・国家特性、「国家」は試合内の所有主体、「指導者」は首都で国を運営する人物、
「指揮官」は領土を移動して軍事・開発を担う人物として整理する案。
過去の開発速度2倍の「リーダー」能力は指揮官の能力として扱い、指導者に自動付与しない。

## 2. 指導者と首都の共通契約案

- 各国1人。指揮官と別枠で、開始時は指導者1人＋指揮官1人（採用済み）。
- 指導者の場所は国家の不変な首都IDを参照する。移動命令・遷都・避難・退却は受け付けない。
- 他国首都を占領しても自国首都は変わらず、相手の指導者を獲得しない。
- 初回は指導者の解雇・交代・継承・暗殺・個人HP・装備を設けない案。
- 指導者は移動軍団を持たず、単独では首都を守る兵力にならない案。
  首都の守備兵の有無・初期配置は戦闘と初期状態のSPECで定義する。
  指導者がいることだけを理由に無人首都への占領を拒否しない。
- 人物名・肩書・肖像は派閥の表現に用い、個別の能力選択や育成は初回案に加えない。
- 本仕様の1国脱落はゲーム上の結果であり、指導者の死亡等の物語表現は後で決める。

## 3. 4派閥の構成案

下表の4つの方向性は了承済み。名称・肩書・能力の数値や適用条件は提案として詰める。
同条件で違いを比較するため、初期資金・資材・開始兵力・通常の指揮官能力候補は共通にする案。
4派閥を各1国ずつ配置する。人間が選んだ派閥以外の3派閥をAIへ割り当てる（68A）。重複は不可。

| 派閥の仮称 | 指導者の肩書案 | 中核特性案 | 得意な判断 |
| --- | --- | --- | --- |
| 城塞公国 | 公爵 | 諸侯の結束: 指揮官上限6人 | 追加の指揮官を前線・偵察・開発へどう配分するか |
| 深緑盟約 | 長老議長 | 森の帳: 森にいる自軍の兵力を通常観測から隠す | 森に主力を置くか、少数軍で警戒させるか |
| 風原連邦 | 大族長 | 行軍補給: 敵領・中立地でも軍団が20%自然回復する（66A） | 自領へ戻らず攻勢を続けるか |
| 河港同盟 | 総督 | 渡し守: 橋のない川を渡れる | 橋を使う正面攻撃と別地点の渡河をどう使い分けるか |

### 城塞公国: 組織で戦う

- 通常5人に対して6人を指揮できる。最初から6人いるわけではない。
- 中立部隊の撃破・ランダムイベントで追加の人物を得て、兵力は通常の費用で整える。
- 7人目を迎える場合は既存指揮官の解雇が必要。指導者の別枠については第1節の回答に従う。
- 6人目を得る前はこの特性の利益がない。追加収入や防衛補正を同時に付けない。
- 旧案の防衛時の退却先指定は、この派閥の中核特性から外す。指揮官側の殿軍能力とは重ねない。
- 評価: 獲得までの時間、6人目の内政効果、最大人数時の入力時間を確認する。

### 深緑盟約: 情報を隠して戦う

- 森にいる軍の存在は見えるが、通常観測では兵力を「不明」とする。0や虚偽の数を返さない。
- 味方の正確な兵力は常に本人へ見せる。平地・山では共通の観測規則へ戻る。
- 戦闘相手には、戦闘参加時点で共通の戦闘結果契約が許す情報を開示する。
- 「精察」能力を持つ指揮官の偵察だけが隠蔽を見破れる（67A）。通常偵察では兵数は不明のまま。
  兵士一覧の件数等で兵数が分かる情報も通常偵察へ渡さない。敵の命令や移動履歴は得られない。
- 領有・地形・発展段階を隠す能力にはしない。これらの基本公開範囲は共通仕様に従う。
- 評価: 森の配置次第で無意味または常時有効にならないこと、偵察に行動を使う価値を確認する。

### 風原連邦: 整えながら戦線を変える

66A採用: 自領内の移動と補充を同時実行する旧案を撤回する。

- 軍団の生存兵は、ターン末に敵領・中立地にいても最大HPの20%を自然回復する。
- 自領では共通の20%回復のみ。合計40%にはしない。行動や購入の追加操作は不要。
- 自領への帰還を待たず、次ターンの戦闘へ回復した状態で臨める。
- 回復費用は不要。HP上限・負傷離脱中は対象外・休養との二重回復なしという共通条件を守る。
- 休養は他派閥と同じく自領限定・全回復。移動距離、徴兵可能地点、兵数は増やさない。
- 守備隊は共通の20%回復。特性による追加倍率は付けない。
- 評価: 補給のために撤退する必要性と、連続侵攻時の優位が過大でないかを比較する。

### 河港同盟: 経路を増やして戦う

- 川はマス間の辺で表し、河港同盟は橋のない川の辺も通常移動で通過できる。
- 上下左右1マスの隣接制約は維持し、追加行動・2マス移動・海や湖への進入を得ない。
- 渡河能力は退却にも適用する（69A）。退却先が戦闘後も安全な隣接自領である共通条件は維持する。
- 橋・通常の渡河地点はマップ生成時に固定し、試合中の建設・破壊はしない（70A）。
  能力で通過しても他派閥用の渡河地点は残らない。
- 評価: 全派閥に首都への通常の陸路を残したうえで、有効な渡河の迂回路を用意できるか。

## 4. 人気・科学力と指導者アクション

### 4.1 共通3命令への改訂案

全派閥共通で毎ターン1つを選び、指揮官とは別の命令枠を使う（採用済み）。
ユーザー指定の徴税・研究・人気向上を中心に、旧案の資材調達・首都開発・首都警戒は
初回の指導者命令から外す。3命令に限定する構成は採用済み。
首都を含む領土開発と偵察は指揮官、通常の資材生産は領土が担う。

| 命令 | 採用された方向 | 調整用の提案 |
| --- | --- | --- |
| 徴税 | 追加資金を得て、人気が下がる | ターン末に固定額を得る。人気-15。追加資金は翌ターンから使う |
| 研究 | 科学力を上げる | 研究点+1。必要点に達すると科学Lvが上がる |
| 人気向上 | 人気を上げる | 人気+20。表示名は「民心掌握」も候補 |

通常の領土収入はどの命令でも得られる。徴税額は人気や領土数に比例させず共通固定額から試す。
研究・人気向上は指導者の1行動だけを費用とし、資金不要（64A）。資材の追加支払いも設けない。
人気向上は減税・住民との対話などをまとめた政治活動とし、必ず資金を消費する祭典とは定義しない。
未入力を徴税へ自動補完する旧案は撤回。人気を勝手に消費しないよう、待機を補完する案。
上限時の人気向上・研究は受付で拒否し、実行可能な命令または待機を明示選択する案。

### 4.2 人気（範囲・初期値・増減・倍率を採用）

人気は0〜100の整数、初期50。徴税で-15、人気向上で+20（62A）。
毎ターンの自然減少・自動回復は設けず、最初は徴税と人気向上だけで動かす。
勝敗や占領による自動増減は追加検討とし、現時点で含めない。

| 人気 | 通常の領土資金収入への補正（63A採用） |
| --- | --- |
| 0〜24 | -10% |
| 25〜49 | ±0% |
| 50〜74 | +10% |
| 75〜100 | +20% |

人気補正は通常の資金収入だけに適用する（59A）。徴税の臨時収入・資材・戦闘・雇用費・加入確率には適用しない。
通常の資金収入を国家単位で合計してから倍率を適用し、小数は切り捨てる案。
人気向上は100で打ち止め。徴税には開始時人気15以上を要求し、0未満への切り捨てで
無制限に徴税できる状態を避ける（62A）。低人気でも通常収入は残し、反乱や強制脱落は導入しない案。
人気15未満でも人気向上で回復でき、資金不足による回復不能を作らない。

上記の人気値・増減・倍率は62A・63Aで採用済み。高人気維持と徴税の価値は未検証のため、
基礎収入・徴税額・試合ターン数と合わせて調整する。

### 4.3 科学力（対象・倍率・研究閾値を採用）

人気は上下する支持、科学力は研究で蓄積する国家の知識として区別する。
科学力はLv0〜3の一本とする（60B）。研究分野・技術ツリーは初回に設けない案。
研究1回で研究点1。累計2／5／9点でLv1／2／3（61A）。初期Lv0・研究点0を前提とする。
領土喪失で下がらず、研究点を消費資源にせず、他国の科学力は占領で継承しない案。

60B採用: 科学Lvごとに通常の資材生産+20%、軍の攻撃・防御+10%。

| 科学Lv | 累計研究点 | 資材生産補正 | 攻撃・防御補正 |
| --- | --- | --- | --- |
| 0 | 0 | 0% | 0% |
| 1 | 2 | +20% | +10% |
| 2 | 5 | +40% | +20% |
| 3 | 9 | +60% | +30% |

科学力だけの倍率は資材が1+0.2×Lv、攻撃・防御が1+0.1×Lv。1.2や1.1をLv回乗算しない。
国家単位の通常資材生産を合計して倍率を適用し、小数は切り捨てる案。
科学力の攻撃・防御補正は軍団・守備隊の両方へ適用する（65A）。
他の特性・地形との加算順は未決定。開発費割引は追加しない案。
指揮官の開発2倍能力は命令で進む段階数に効き、科学力は段階上限や開発速度を変更しない。

試合は30ターン上限。9回の研究による投資と補正のバランスは未検証。終盤までに到達できることと、
研究ばかりが最善にならないことを、徴税・人気向上の機会費用と合わせて検証する。

## 5. 首都陥落・同時解決・情報制限

首都は初期設定のIDを維持し、指導者の命令から変更する経路を作らない。
他国首都を取った国も、自国首都が同時に落ちれば既存ルールどおり脱落する。
人気・科学力・指導者命令には陥落を取り消す効果を持たせない。

指導者の徴税・研究・人気向上の結果は、脱落判定後に生存国にだけ生成する案。
当該ターンの補正は開始時の人気・科学力を参照し、更新後の値は翌ターンから適用する。
そのターンに首都戦闘が起きても生存していれば選択した1命令を実行する案。
終局後に次の命令を要求しない。生存国全体の確定を待ち、脱落国の入力は待たない。
開始時点の資金・資材に対して指揮官命令と指導者命令の費用をまとめて予約する。
同ターンの徴税で同ターンの補充費を払う等の先払いは認めない案。

派閥の種類と中核特性、固定の首都位置、指導者の肩書は公開する案。
指導者の選択命令・相手国の在庫・非公開軍勢は渡さない。
人気・研究点・科学Lvの正確な値は自国にだけ渡す案。公開範囲は最終決定前。
資金増加や命令受付エラーから他国の秘密命令を推測できる出力を作らない。
AIの指導者命令も、同じプレイヤー別Observationだけから選ぶ。

## 6. 実装境界と必要な検証

国家は不変の首都ID・派閥ID・指導者・人気・累計研究点を保持する案。
科学Lvはルール版の閾値から求め、保存する場合は研究点との整合を検証する。
指導者命令は国家ID・ターン・命令種別を持ち、移動先フィールドを持たせない。
指揮官命令と共通のapplication受付から検証・確定・解決し、UIとCLIで結果を一致させる。
既存の加入・解雇が指導者を対象にできないようにする案。

具体的な資源量や戦闘式を決めた後に検証する例:

- 指導者の移動・遷都・他国の指導者への命令を拒否し、状態を変えない。
- 両国の首都同時陥落でも指導者の命令によってどちらかが復活しない。
- 城塞公国の6人目は可能、他の派閥の6人目・同国7人目は解雇なしで加入できない。
- 深緑盟約の未公開兵力を変更しても、通常観測出力から数値が漏れない。
- 風原連邦でも資金不足や戦闘中の補充が成功しない。
- 河港同盟でも斜め・海・湖の移動を拒否する。
- 複数命令の二重支出、脱落国への追加収入・人気増加・研究進捗を防ぐ。
- 人気の閾値・上限・徴税受付下限、科学Lvの累計閾値と上限を検証する。
- 当該ターンの収入には開始時の補正を使い、更新後の補正は翌ターンにだけ適用する。
- 国別合算後の端数処理を固定し、同じ入力・ルール版から同じ収入を得る。
- 自国の通常収入以外へ人気補正を掛けず、敵の人気・研究点をObservationへ漏らさない。
- 最大6指揮官＋指導者1命令でも、戦況確認・命令入力が過度に増えないかを実機で確認する。

受入時は4派閥を全開始位置で比較する。地形依存の能力が働かない配置を避け、
指導者の追加収入が領土開発の価値を消さないよう、値を試遊で調整する。
文書の作成は能力・指導者命令の実装やバランス検証の完了を意味しない。

## 7. 採用待ちの判断

1. 科学力の倍率・研究閾値・守備隊への適用は採用済み。他の補正との重複順を決める。
2. 指導者の3種類・毎ターン1命令、研究・人気向上の資金不要は採用済み。徴税額を決める。
3. 人気の範囲・初期値・増減・徴税下限・倍率は62A・63Aで採用済み。収入に参照する時点を決める。
4. 端数・公開範囲・待機を具体化する。戦闘と作業の順序はSPEC 009に従う。
5. 4派閥の能力適用条件と指導者の守備兵を具体化する。

人気・科学力と3アクション、上記の採用数値を記録した。残る計算詳細は提案であり、実装・試遊は未実施。
