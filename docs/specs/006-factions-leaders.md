# SPEC 006: 4派閥と首都の指導者

作成日: 2026-09-10 / 状態: **首都固定・指導者移動不可は採用済み、詳細は提案、未実装**。
関連: [基本仕様](003-release-map-factions.md) / [指揮官](004-commanders.md) /
[開発・経済](005-territory-development.md)

## 1. 採用された要件

- 各国家に指導者を置き、指導者が毎ターン実行するアクションを設ける。
- 首都は試合中に変更できず、指導者は首都から移動できない。
- 首都が陥落した国家は脱落する。残存1国が勝利し、全国家同時脱落は引き分けという既存要件を維持する。
- 指揮官の在籍上限は通常5人、4派閥のうち1派閥のみ6人。
  指導者は指揮官の在籍上限とは別枠（ユーザー承認済み）。
  開始時は指導者1人＋指揮官1人、最大は指導者1人＋指揮官5人（特定派閥6人）。

「Faction」は文化・国家特性、「国家」は試合内の所有主体、「指導者」は首都で国を運営する人物、
「指揮官」は領土を移動して軍事・開発を担う人物として整理する案。
過去の開発速度2倍の「リーダー」能力は指揮官の能力として扱い、指導者に自動付与しない。

## 2. 指導者と首都の共通契約案

- 各国1人。指揮官と別枠で、開始時は指導者1人＋指揮官1人（採用済み）。
- 指導者の場所は国家の不変な首都IDを参照する。移動命令・遷都・避難・退却は受け付けない。
- 他国首都を占領しても自国首都は変わらず、相手の指導者を獲得しない。
- 初回は指導者の解雇・交代・継承・暗殺・個人HP・装備を設けない案。
- 指導者は移動軍団を持たず、単独では首都を守る兵力にならない案。
  首都の守備兵の有無・初期配置は戦闘と初期状態のSPECで定義する。
  指導者がいることだけを理由に無人首都への占領を拒否しない。
- 人物名・肩書・肖像は派閥の表現に用い、個別の能力選択や育成は初回案に加えない。
- 本仕様の1国脱落はゲーム上の結果であり、指導者の死亡等の物語表現は後で決める。

## 3. 4派閥の構成案

下表の名称・肩書・割当・能力詳細は採用待ち。上限+1の存在だけは採用済み。
同条件で違いを比較するため、初期資金・資材・開始兵力・通常の指揮官能力候補は共通にする案。
各派閥を1枠ずつ配置する案を推奨するが、重複選択の可否はまだ未決定。

| 派閥の仮称 | 指導者の肩書案 | 中核特性案 | 得意な判断 |
| --- | --- | --- | --- |
| 城塞公国 | 公爵 | 諸侯の結束: 指揮官上限6人 | 追加の指揮官を前線・偵察・開発へどう配分するか |
| 深緑盟約 | 長老議長 | 森の帳: 森にいる自軍の兵力を通常観測から隠す | 森に主力を置くか、少数軍で警戒させるか |
| 風原連邦 | 大族長 | 行軍補給: 自領内の通常移動と補充を同時に行える | 部隊を整えながらどの戦線へ送るか |
| 河港同盟 | 総督 | 渡し守: 橋のない川を渡れる | 橋を使う正面攻撃と別地点の渡河をどう使い分けるか |

### 城塞公国: 組織で戦う

- 通常5人に対して6人を指揮できる。最初から6人いるわけではない。
- 中立部隊の撃破・ランダムイベントで追加の人物を得て、兵力は通常の費用で整える。
- 7人目を迎える場合は既存指揮官の解雇が必要。指導者の別枠については第1節の回答に従う。
- 6人目を得る前はこの特性の利益がない。追加収入や防衛補正を同時に付けない。
- 旧案の防衛時の退却先指定は、この派閥の中核特性から外す。指揮官側の殿軍能力とは重ねない。
- 評価: 獲得までの時間、6人目の内政効果、最大人数時の入力時間を確認する。

### 深緑盟約: 情報を隠して戦う

- 森にいる軍の存在は見えるが、通常観測では兵力を「不明」とする。0や虚偽の数を返さない。
- 味方の正確な兵力は常に本人へ見せる。平地・山では共通の観測規則へ戻る。
- 戦闘相手には、戦闘参加時点で共通の戦闘結果契約が許す情報を開示する。
- 偵察型の精察では兵力を見破れる案を推奨。敵の命令や移動履歴まで得る効果にはしない。
- 領有・地形・発展段階を隠す能力にはしない。これらの基本公開範囲は共通仕様に従う。
- 評価: 森の配置次第で無意味または常時有効にならないこと、偵察に行動を使う価値を確認する。

### 風原連邦: 整えながら戦線を変える

- 出発地・到着予定地がどちらも開始時点で自領なら、通常進軍に補充を付けられる。
- 移動成功後、戦闘に参加せず、到着地が引き続き自領で補充可能なら補充する。
- 資金費用・補充量・兵力上限は共通。進軍命令に任意の補充予約を付け、開始時残高から費用を予約する案。
  プレイヤーの指定なしに資金を自動消費しない。
- 戦闘・退却・移動不成立・到着地喪失では補充しない。予約金の解放は共通の失敗時支払い契約で定義する。
- 敵領への侵攻や中立地占領と同時に補充はできない。兵を増やしながら攻撃を続ける特性にはしない。
- 強行軍には付けず、通常1マス移動だけに適用する案。移動距離・補充回数は増やさない。
- 旧強行軍案は指揮官能力に残し、この派閥では後方から前線へ軍を整えつつ送る強みを作る。
- 評価: 追加操作の負担、補充に使う命令を省ける価値、資金消費と陣地転換の頻度を確認する。

### 河港同盟: 経路を増やして戦う

- 川をマス間の辺として表す案の採用を前提に、橋のない川の辺も通常移動で通過できる。
- 上下左右1マスの隣接制約は維持し、追加行動・2マス移動・海や湖への進入を得ない。
- 同時移動・到着時戦闘・退却は共通規則に従う。川を越える能力を退却にも適用するかは未決定。
- 橋の新設や破壊は行わず、通過後に他派閥用の渡河地点が残ることもない。
- 評価: 全派閥に首都への通常の陸路を残したうえで、有効な渡河の迂回路を用意できるか。

## 4. 指導者の毎ターンのアクション案

最初は全派閥に共通の4命令から毎ターン1つ。派閥専用の指導者命令は増やさず、
中核特性を国家全体へ常時適用して差を付ける案を推奨する。
この構成自体も未採用。指揮官の命令枠とは別に、国家の命令一式に含めて確定する。

| 命令 | 効果案 | 費用・時点・制約 |
| --- | --- | --- |
| 徴税 | 国家に追加の資金を得る | 指導者の1行動。生存していればターン末に獲得し、翌ターンから使用 |
| 資材調達 | 国家に追加の資材を得る | 同上。資金からの交換ではなく、このターンの生産への注力 |
| 首都開発 | 首都の発展Lvを上げる | 共通の段階別資材費を使う。首都だけが対象で、通常の開発上限を超えない |
| 首都警戒 | 首都周辺の観測範囲を一時的に広げる | 指導者の1行動。そのターンの結果で得る情報を増やし、戦闘補正・追加兵は生まない |

命令の意味は「今すぐ兵を整えるための資金」「開発用資材」「将来の基盤」「次の危険を知る情報」。
指導者を徴税へ回すと、そのターンの資材調達・開発・警戒はできない。
移動指揮官は全員出撃していても、首都側で国家運営を行える。

具体化の案:

- 徴税・調達の量は全派閥共通の固定量から試す。領土数に比例させず、劣勢だけ増やす補正もしない。
  資金量・資材量の値は兵力費用・開発費・地形収入と一緒に決める。
- 通常の領地収入は命令によらず得られる。徴税・調達を選ばないと基礎収入が止まる仕様にはしない。
- 首都開発は本人が通常1段階分を進める案。指揮官の得意地形開発能力は適用しない。
- 指導者と指揮官が同じターンに首都開発を指定したら、国家の命令検証で重複を拒否する。
  どちらを担当にするかを選び、1領地1ターン1開発の原則を保つ。
- 首都警戒は候補としてマンハッタン距離2の観測を与える。通常の首都視界は距離1を候補とする。
  山の視界・森の隠蔽との優先順位を決める。警戒は精察ではないため、深緑盟約の兵力を見破らない案。
- 警戒の結果は全移動・戦闘後のスナップショット。途中経路や同ターンの敵命令を予知しない。
  警戒したターンに首都が落ちれば、その情報で命令を差し替えて陥落を防ぐことはできない。
- 通常の警戒範囲が他の効果で広がっている場合、範囲を加算せず大きい方を採る案。
- 首都が戦闘に参加したターンの開発は共通規則で中断。徴税・調達・警戒を中断するかは未決定。
- 未入力は徴税へ補完する案。経済上の中立な自動選択ではないので、確定前に明示する。
- 任意のターンで無行動を許すかは未決定。命令不能時の待機も含めて受付契約を完成させる。

## 5. 首都陥落・同時解決・情報制限

首都は初期設定のIDを維持し、指導者の命令から変更する経路を作らない。
他国首都を取った国も、自国首都が同時に落ちれば既存ルールどおり脱落する。
警戒・徴税・調達・首都開発には陥落を取り消す効果を持たせない。

指導者の徴税・調達・開発・警戒の結果は、脱落判定後に生存国にだけ生成する案。
終局後に次の命令を要求しない。生存国全体の確定を待ち、脱落国の入力は待たない。
開始時点の資金・資材に対して指揮官命令と指導者命令の費用をまとめて予約する。
同ターンの徴税で同ターンの補充費を払う等の先払いは認めない案。

派閥の種類と中核特性、固定の首都位置、指導者の肩書は公開する案。
指導者の選択命令・相手国の在庫・非公開軍勢は渡さない。
資金増加や命令受付エラーから他国の秘密命令を推測できる出力を作らない。
AIの指導者命令も、同じプレイヤー別Observationだけから選ぶ。

## 6. 実装境界と必要な検証

国家は不変の首都ID・派閥ID・指導者を保持する案。
指導者命令は国家ID・ターン・命令種別を持ち、移動先フィールドを持たせない。
指揮官命令と共通のapplication受付から検証・確定・解決し、UIとCLIで結果を一致させる。
既存の加入・解雇が指導者を対象にできないようにする案。

具体的な資源量や戦闘式を決めた後に検証する例:

- 指導者の移動・遷都・他国の指導者への命令を拒否し、状態を変えない。
- 両国の首都同時陥落でも指導者の命令によってどちらかが復活しない。
- 城塞公国の6人目は可能、他の派閥の6人目・同国7人目は解雇なしで加入できない。
- 深緑盟約の未公開兵力を変更しても、通常観測・警戒出力から数値が漏れない。
- 風原連邦でも資金不足や戦闘中の補充が成功しない。
- 河港同盟でも斜め・海・湖の移動を拒否する。
- 首都開発の重複、複数命令の二重支出、脱落国への追加収入を防ぐ。
- 最大6指揮官＋指導者1命令でも、戦況確認・命令入力が過度に増えないかを実機で確認する。

受入時は4派閥を全開始位置で比較する。地形依存の能力が働かない配置を避け、
指導者の追加収入が領土開発の価値を消さないよう、値を試遊で調整する。
文書の作成は能力・指導者命令の実装やバランス検証の完了を意味しない。

## 7. 採用待ちの判断

1. 指導者の別枠は承認済み。以下の命令・派閥割当の合意へ進む。
2. 4派閥を本書の組織・隠蔽・行軍補給・渡河の方向で具体化するか。
3. 指導者の共通4命令と1ターン1命令を採るか。
4. 指導者の守備兵・戦闘中の内政・未入力・収入量を具体化する。
