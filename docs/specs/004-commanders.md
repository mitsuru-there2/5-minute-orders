レアイベントは毎ターンランダムに抽選する方式を採用。

## 1. 前提と今回の検討範囲

既存要件は開始時1指揮官、軍団の指揮、短時間の命令入力。
今回のユーザー指定により初回の在籍上限を通常5人、1派閥だけ6人へ変更する。
原案の将来5〜7人という構想は維持する。首都喪失による国家脱落は指揮官の能力では回避できない。

従来は指揮官能力・物語的加入を初期版から外し、人数の異なる検証配置を使う案だった。
中立部隊撃破で指揮官だけが加入する方式を採用済み。撃破判定や加入配置などの詳細は検討中。
指揮官の役割差・能力を含める範囲は引き続き検討案。
長いイベント分岐・多数の人物・魔法体系の制作は本案にも含めない。

## 2. 種類は役職と戦術上の役割を分ける案

「王・将軍・騎士・王子」は人物の役職・身分、「守備・機動・偵察」は戦術上の種類とする。
例えば同じ守備型でも、ある派閥では近衛隊長、別の派閥では氏族の長と表現できる。
役職だけで兵力や勝敗を変えず、ルールは役割・能力として明示する。
「王」等を首都の国家指導者として扱う場合はSPEC 006に従い、移動指揮官と兼任させない案。

初回は次の3種類を推奨。全員が軍団を率いて移動・占領・戦闘できる。
偵察型も単独潜入の密偵ではない。魔術師・司祭等の独立した魔法・信仰システムは後回し。

| 種類 | 人物像の例 | 固有能力案 | 使う判断 |
| --- | --- | --- | --- |
| 守備型 | 近衛隊長、老将 | 殿軍: 防衛時に退却先を1つ指定でき、敗戦時に合法なら優先する | どこを守り、どこへ退くか |
| 機動型 | 騎士隊長、辺境将軍 | 強行軍: 平地経路を指定して2マス移動できる | どの戦線へ早く戦力を送るか |
| 偵察型 | 斥候長、案内人 | 精察: 偵察で指定した領地の兵力を詳しく調べる | 不確かな敵に踏み込む前に調べるか |

開始人物の役職は「将軍」を仮置きし、戦術型は開始時に選ぶ案。
その後も加入時に型を選び、同じ型の重複を許す案とする。
守備・機動・偵察を必ず1人ずつ集める仕様にはしない。
指揮官の恒常的な転職・能力の付け替えは初回案に含めない。

## 3. 加入は中立部隊の撃破＋毎ターンのランダムイベント

### 採用済みの方式

- 通常加入は中立地の部隊を倒すことで、指揮官だけが味方になる方式を採用。
  中立兵の引き継ぎや無料の新軍付与は行わない。加入配置・勝者判定などの詳細は未決定。
- 通常加入に加えて、毎ターンの完全にランダムなレアイベントでも人物が加入する。
  領土数や防衛実績を発生条件にせず、戦況に応じた救済確率の上乗せもしない。
  毎ターン抽選することと、毎ターン必ず誰かが加入することは区別する。
- 旧案の「第3・第6ターンに全国家へ加入保証」は撤回。
  戦歴は人物紹介だけでなく、加入条件にも使える設計として検討する。
- 通常上限5人・特定1派閥の上限6人を採用。上限時に新しい人物を採用するには、在籍者を解雇する。

### 中立部隊による通常加入のたたき台（未採用）

- 中立地の一部に指揮官付きの部隊を配置する。無人の中立地を占領しただけでは加入しない。
- 部隊を撃破すると、その指揮官が加入候補になる案。加入先は戦闘の勝者とする。
- 既存の3種類案を採る場合は、探索中に見つけた人物の型が加入後も続く案。
  戦闘のたびに自由な型へ変換する方式と、第2節の自由選択案は同時採用しない。
- 中立部隊はその領地を守り、自発的に侵攻・領土拡大しない案。
  中立は5人目のプレイヤーや5つ目の派閥ではないが、戦闘参加者として扱う必要がある。
- 観測した場合だけ、その部隊の存在・獲得可能な人物をプレイヤーへ示す。
  候補一覧を通じて未観測の中立部隊を漏らさない。
- 指揮官だけが加入し、残存兵は加わらない（採用済み）。兵力0から軍を整える方法は補充・資源と合わせて決める。
- 初期配置・部隊数・強さ・再出現・国家脱落後に中立化した領地への出現は未決定。
  脱落国の軍を除去する既存契約は維持し、撃破対象の中立軍へ自動変換しない。
- 複数国の同時攻撃では、最終的な勝者が未確定のうちに候補を配らない。
  引き分け・相打ち・勝者の同ターン脱落・複数撃破による複数候補の扱いは契約化が必要。

中立軍へ割く兵力と敵国への備えが競合することを検証する。
4陣営間で獲得機会が偏らない配置と、5人目・6人目を獲得できるだけの候補数を設計する。

### 公開条件案の旧比較記録（現行推奨から外す）

| 機会 | 条件例 | 人物の登場文の例 |
| --- | --- | --- |
| 最初の1人 | ゲーム開始時（既存要件） | 国を率いる将軍 |
| 通常加入の1件目 | 同時に4領地以上を保有 | 領土の拡大を見た騎士が仕官する |
| 通常加入の2件目 | 同時に8領地以上を保有 | 新たな軍を率いる将軍が参陣する |
| 公開条件の別候補 | 防衛戦で累計2回成功 | 城壁を守った隊長が抜擢される |

4・8・2という数値は未採用の比較用。初期領土数・初期兵力・戦闘の勝敗定義と合わせて決める。
防衛条件を領土条件の代替にするか、特定人物専用にするかも未決定。
条件ごとに得られる人物を固定するか、型を選べるようにするかは別途判断する。
第2節の加入時の型選択は引き続き候補であり、この加入方式から自動的には確定しない。

領土条件の数え方は、自国が現在保有する陸地マスを首都込みで数え、水マスを除く案。
累計占領数ではなく同時保有数を使い、同じ土地の奪還を繰り返して水増ししない。
最初から「条件・現在の進捗・得られる人物または選択肢」を表示する案。
領土条件だけでは優勢国が人数でも先行するため、条件到達時期と加入軍の兵力を比較し、
防衛等による別経路の必要性を検証する。固定ターン保証には戻さない。

### レアイベント（毎ターンのランダム抽選は採用、詳細は未採用）

例は戦歴条件によらず「旅の騎士が仕官を申し出る」。
旧案の「不利な防衛戦を切り抜けた後」という条件付きの救援イベントは採らない。
各生存国に毎ターン同じ確率で独立した抽選を行う案を推奨する。
全体で1回抽選して受益国を選ぶ案との比較、発生確率、候補の抽選分布は未決定。
首都陥落や試合終了を取り消して加入させない。

- レア加入も各国の上限5人／6人の枠を使う。枠がないことを理由にイベントの確率を変更しない案。
- 満員でも候補は提示し、解雇して迎えるか加入を見送るかを選ぶ案。
  旧案の自動保留は現行推奨から外す。候補の有効期限・複数候補の選択順は未決定。
- ランダムな結果は固定seed・ルール版・状態から再現できるようにし、時計・グローバル乱数を使わない。
  保存再開や同一ターンの重複処理で抽選し直さない。
- 中立部隊撃破を主な人数増加の経路とし、レア加入がなくても対戦できる構成を検証する。

### 加入処理と上限時の入れ替え

全移動・戦闘・退却・占領・脱落と終局判定を解決した後、試合が続く場合に生存国の加入候補を処理する案。
候補の決定・配置を経て、次のターンから命令可能とする案。
撃破した部隊IDとイベント発生IDに紐付け、同じ候補を二重に加入させない。
中立部隊撃破とレア加入が同時発生した場合の選択順は実装前に確定する。

満員時は通常派閥なら6人目、上限拡張派閥なら7人目の加入に解雇が必要（採用済み）。
実装案は「候補確認→加入を見送る／解雇する人物を選ぶ→入れ替え確定」。
一時的にも上限を越えず、解雇と採用をまとめて確定する。
解雇対象の軍団・兵力・所在領地、開始人物の解雇可否は未決定。
軍団の自動移管や兵力の即時転送を暗黙に追加せず、解雇後の再雇用可否も別途決める。

配置は自国首都を候補とする。既存軍がいても同居できる案で、首都からの出撃に命令を使う。
中立由来の加入には新軍を付けない。レアイベント加入時の兵力はまだ未決定で、今回の承認を自動適用しない。
加入時に自動で領土や資金を得る効果は設けない。

「新規加入」と「戦闘で失った人物の補充」は別の問題。
通常5人・特定派閥6人は在籍枠の上限とし、負傷中の人物も枠を使う案。
戦死・捕虜・負傷復帰のどれを採るかはまだ未決定。喪失した枠の再補充も未採用。
敗北で人物を失うルールの採用前に、1人しかいない序盤に継続可能かを確かめる。

## 4. パラメータ案

人物の個性と軍の消耗を混同せず、最初は数値を絞る。

| 区分 | 項目 | 扱い |
| --- | --- | --- |
| 人物 | ID、所属国、名前、役職、戦術型 | 名前と役職は表現。IDと所属はルール用 |
| 人物 | 固有能力 | 初回は1人1能力、型に対応した固定能力 |
| 人物 | 経歴・短い人物紹介 | 実際の戦歴由来の紹介。性格による勝手な命令変更はしない |
| 状態 | 現在地、現在命令、確定状況 | 指揮官カードから確認できる |
| 状態 | 活動可能か | 負傷等の採用時に定義。現段階で負傷を実装済みとしない |
| 軍団 | 現在兵力／上限兵力 | 戦闘・補充で変化。具体値は未決定 |
| 共通ルール | 通常移動距離・視界 | 共通値を基本に、地形や能力による例外だけ変える |

統率・武勇・知略・魅力・忠誠・経験値・装備の多重管理は初回案に含めない。
特に「知略が高いほど偵察に確率成功」ではなく、偵察で得る情報を能力の契約として説明する。
指揮官個人のHPと軍団兵力の二重管理も、敗北処理で必要になるまでは追加しない。
将来能力を拡張するためだけの未使用パラメータは保存データへ入れない。

## 5. 毎ターンの基本命令案

1指揮官につき次から1つ。複数アクションを同時指定しない。
開発命令の追加は採用済み。他の基本命令の詳細と1人1命令の契約は引き続き提案。

| 命令 | 行動と効果案 | 代わりにできないこと |
| --- | --- | --- |
| 進軍 | 通れる上下左右の隣接領地へ移動。敵軍がいれば戦闘、無人なら占領処理 | 防衛・偵察・補充を同時に行えない |
| 防衛 | 現在地に留まり、防衛効果を得る | 移動・能動偵察・補充はしない |
| 偵察 | 現在地に留まり、指定した領地の解決後の情報を得る | 移動せず、防衛命令による効果を得ない |
| 補充 | 自領に留まり、自軍の兵力を上限までの一定量だけ回復する | 移動せず、防衛命令による効果を得ない |
| 開発 | 自領に留まり、その領地の発展段階を上げる。詳細はSPEC 005の提案 | 同時に進軍・防衛・偵察・補充はできない案 |

攻撃は進軍の結果として扱い、別の攻撃ボタンにしない。
通常の退却は戦闘結果から発生する処理で、毎ターンの独立した命令ではない。
自ら安全な領地へ下がる場合は進軍命令で自領を指定する。
未入力は防衛に補完し、確定前に確認画面で示す案。毎ターン前回の進軍を自動継続しない。
攻撃を受けた偵察・補充中の軍も戦うが、命令による防衛効果は得ない。
森などの地形効果は、採用する地形ルールに従って別途判定する。

補充は自軍がそのターン戦闘に参加したら不成立とする案で、首都でも例外にしない。
補充量・どの自領で可能か・消費資源を必要とするかはD06で決める。
領土開発による資源収入を採用したため、経済を省略する旧案を見直し、SPEC 005で資源を使う補充を検討する。

## 6. 能力は基本命令の拡張にする案

追加候補: [SPEC 005第7節](005-territory-development.md)に、平地の「開拓の才」、森の「森林経営」、
山の「山地普請」を追加。本人の得意地形で開発進捗を2倍にする案。
資材割引・収入倍増は含めず、既存3種類への分類方法と1人1能力案との整合は今後決める。

- 殿軍は防衛命令の任意の退却先指定として表現する。
  敗戦や損害を無効にせず、指定先が解決時に不適格なら共通の退却規則へ戻す。
  指定しなかったときも共通処理にする。退却不能の扱いは共通仕様を先に決める。
- 強行軍は進軍命令の経路指定として表現する。通常進軍も選べる。
  2マス移動中の衝突、途中の占領、水辺の通過、停止位置はSPEC 002で解決するまで未定。
- 精察は偵察命令で得られる情報を増やす。
  通常偵察は軍の存在・規模の概数、精察は兵力の正確な数を得る案。
  敵の未確定命令・移動履歴・他所の軍は渡さない。
  地形や派閥の隠蔽をどこまで見破れるかは対抗ルールとして決める。

偵察対象の範囲はマンハッタン距離2以内を候補とし、移動の隣接関係とは区別する。
結果は同ターンの全移動・戦闘・脱落後の状態から生成し、過去情報には対象ターンを記録する案。
偵察担当が除去・退却した場合の成否、結果の保持、山の視界との関係は未決定。
秘密の敵の有無で命令の合法性を変えない。未知の兵力を0として出力しない。

能力ごとのAP・MP・クールダウンは初回案に加えない。
同時に1命令しかできない機会費用と、地形・戦闘・配置上の制約を先に検証する。

## 7. 派閥案との重複を解消する

4派閥のうち1派閥だけ指揮官上限を通常より1人増やす特性を採用。
どの派閥へ割り当てるかは未決定。初回の全体最大は6人で、他の3派閥は5人。
この特性は開始人数や自動加入数を増やさず、追加の1人も通常の加入経路で得る。
追加軍団を持てる効果は大きいため、その派閥の中核能力として扱う案を推奨。
SPEC 003の旧能力へ無条件に追加で載せる決定にはしない。

SPEC 003の城塞公国の退却先指定、風原連邦の強行軍は本書の指揮官能力と重複する。
両方をそのまま採用し、同じ効果を重ねる設計にはしない。
指揮官は「この軍団でできる行動」、派閥は「国家全体の戦い方」を担当する方向を推奨。

本書の3種類を採る場合は、4派閥の能力を再検討する。
例えば派閥まで同じ強行軍を持たせてさらに4マス移動できるようにする等の暗黙の加算は禁止。
派閥の新能力はこの文書で確定しない。4派閥・3種類の組み合わせと対抗手段を次に比較する。

## 8. 合意と実装前に必要なこと

上限5人／6人と満員時の解雇、毎ターンのランダムイベントは確定。
中立部隊撃破で指揮官だけが加入する方式と開発命令も採用済み。
次に、解雇・兵力0の人物の扱い、3種類・開発を含む5命令の詳細を相談する。
採用後に、加入選択の確定手順、AIの選択、未選択時の動作、配置と新軍兵力を定義する。
戦闘・退却・補充・視界を一緒に詰め、軍団が空になったときの人物の扱いも確定する。
指揮官加入は解決中に割り込ませず、次の命令受付へ進むapplicationの境界で扱う案。

必要な紙上例・後続の行動テスト:

- 中立部隊撃破と首都喪失が同ターンに発生しても、脱落した国へ加入しない。
- 加入選択を再提出しても同じ機会から人物・兵力を二重に獲得しない。
- 同一の撃破済み中立部隊や同一イベントから二重加入しない。
- 複数候補が同時発生しても在籍上限5人／6人を越えず、加入を見送った場合は在籍者を解雇しない。
- 同一seed・状態・ルール版から同じレア候補を得る。抽選回数や配列順で結果が変わらない。
- 隠れた敵の兵力を変えても、偵察命令の受付結果は変わらない。
- 補充中に攻撃された軍が、防衛効果と補充を二重に得ない。
- 通常5人・最大6人の基本命令と任意指定、加入時の入れ替えを5分以内で入力できるか、実機で確認する。
